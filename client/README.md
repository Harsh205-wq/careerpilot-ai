# CareerPilot AI Client

This folder contains a Vite + React client organized under `src/` without an
extra nested app folder.

## Run locally

```bash
npm install
npm run dev
```

## Structure

- `src/main.jsx` - React bootstrap
- `src/App.jsx` - root application shell
- `src/components` - reusable UI components
- `src/pages` - page-level screens
- `src/context` - auth context setup
- `src/services` - API/service layer starters
- `src/utils` - shared constants
- `src/index.css` - global styles
